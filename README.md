# Hotel Booking Cancellation Analytics Platform

## Project Overview
This project focuses on analysing hotel booking cancellations using SQL, Python, Power BI and a role-based web application.

## Project Objectives
- Organize hotel booking data.
- Analyse booking cancellation patterns.
- Identify important cancellation trends.
- Prepare data for visualization and reporting.
- Develop a role-based analytics application.

## Dataset
The project dataset contains 30,000 booking records and 38 columns, including customer details, booking dates, cancellation status, room types, market segments and revenue information.
