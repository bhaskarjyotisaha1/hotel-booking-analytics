# Project Overview

## Project Title
Hotel Booking Cancellation Analytics Platform

## 1. Introduction
This project focuses on analysing hotel booking data to understand cancellation patterns, customer behaviour and booking trends in the hospitality industry.

## 2. Problem Statement
Hotel booking cancellations affect room occupancy, revenue planning and business operations. Analysing historical booking information helps identify cancellation patterns and supports better management decisions.

## 3. Project Objectives
- Organize hotel booking information.
- Analyse cancelled and confirmed bookings.
- Identify cancellation trends across market segments.
- Understand customer booking behaviour.
- Analyse revenue-related booking metrics.
- Develop interactive dashboards and a role-based web application.

## 4. Dataset Description
The project dataset contains 30,000 booking records and 38 columns.

Important fields include:
- Booking ID and Customer ID
- Customer State
- Arrival Year and Month
- Cancellation Status
- Reservation Status
- Market Segment
- Reserved Room Type
- Lead Time
- Average Daily Rate (ADR)
- Previous Cancellations

## 5. Technologies Used
- MySQL: Database creation and SQL queries.
- Python: Data cleaning, validation and exploratory data analysis.
- Power BI: Interactive dashboard development.
- Google AI Studio: Web application development.
- Supabase: Authentication and backend database services.
