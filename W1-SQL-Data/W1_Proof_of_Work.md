W1 – SQL + Data: Weekly Proof of Work

Project Title
Hotel Booking Cancellation Analytics Platform

1. Objective
The objective of Week 1 was to revise SQL fundamentals and establish the database foundation for our Hotel Booking Cancellation Analytics project.

2. Topics Learned
- Relational databases, tables and relationships.
- Primary Keys and Foreign Keys.
- INSERT, SELECT, UPDATE and DELETE.
- WHERE, ORDER BY and GROUP BY.
- Aggregate functions: COUNT(), SUM() and AVG().
- INNER JOIN and LEFT JOIN.

#3. Project Data Requirements
Identified customer details, hotel information, booking dates, cancellation status, market segment, room type, ADR and customer booking history.

4. Database Design
Designed a relational structure consisting of Customers, Hotels and Bookings tables, using primary and foreign keys to maintain relationships.

5. SQL Implementation
Prepared SQL scripts to create tables, define relationships, insert sample records and retrieve project data.

6. Basic SQL Queries
Practised SELECT, WHERE, JOIN and GROUP BY queries to retrieve bookings, identify cancellations, calculate booking counts and analyse cancellation rates.

7. Individual Contribution
My responsibility was SQL and data foundation. I worked on SQL revision, project data requirements, database design, sample data insertion and basic query testing.

8. Learning Outcomes
Gained practical understanding of relational database design, data organization, table relationships and SQL-based data analysis.
